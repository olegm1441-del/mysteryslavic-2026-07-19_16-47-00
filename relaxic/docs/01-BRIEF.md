# Relaxic — маркетинговый бриф сайта

Источник данных: презентация «Relaxic — сквозной проект по курсу» (слайды 3, 5–14) + бенчмарки.
Всё, что здесь помечено как допущение, ждёт ответа из `00-QUESTIONS.md`.

## 1. Проект

**Продукт.** Наборы для творчества по вселенным кино, сериалов, игр и мультфильмов:
картины по номерам, алмазные мозаики, вышивка крестиком.

**Цель бизнеса.** Рентабельный онлайн-бизнес с выходом на стабильную чистую прибыль
за первый год.

**Роль сайта.** Собственный канал продаж и единственная площадка, где мы управляем брендом
целиком. Маркетплейсы дают оборот, сайт даёт маржу, повторные покупки и аудиторию.

**Задача сайта в одном предложении.**
Довести человека от «увидел любимого персонажа» до «оформил заказ» за 3 клика,
а того, кто ещё не выбрал, — довести до выбора, не бросив наедине с каталогом.

## 2. Ценностное предложение

> Вы не смотрите вселенную — вы собираете её руками.

**JTBD (из презентации, слайд 9):**
Когда человек погружён в любимую вселенную и хочет прожить её глубже, он покупает набор,
чтобы своими руками создать артефакт этой вселенной, расслабиться в процессе
и почувствовать себя частью фандома.

**Что это значит для сайта.** Мы продаём три вещи, и все три должны быть видны на первом экране:
1. **Вселенную** — «у нас есть то, что вы любите»
2. **Процесс** — «эти вечера будут вашими»
3. **Результат** — «это будет висеть у вас на стене»

Конкуренты показывают только третье.

## 4. Сквозные боли → механики сайта

Пять возражений повторяются у всех персон. Под каждое — конкретный элемент интерфейса.

| № | Возражение | Механика | Где |
|---|---|---|---|
| 1 | **«Не знаю, что выбрать»** | Квиз в 3 шага: для кого → вселенная → сколько времени | Главная, `/quiz` |
| 2 | **«Не знаю, справлюсь ли»** | Сложность 1–5 + часы сборки на каждой карточке | Каталог, карточка |
| 3 | **«Что именно я получу»** | «Что в коробке» с фото компонентов | Карточка |
| 4 | **«Можно ли верить»** | Отзывы с фото, галерея работ, гарантия досыла | Сквозные блоки |
| 5 | **«Дойдёт ли и когда»** | Срок и стоимость доставки в карточке, до корзины | Карточка |

Квиз — ключевой элемент. Ни у одного из трёх конкурентов его нет,
а «не знаю, что выбрать» — это главный барьер в категории, где товар выбирается эмоцией.

## 5. Пути клиента

### A. Екатерина — «занять ребёнка»
```
Яндекс «чем занять ребёнка 7 лет»
   → Статья «10 занятий без экрана» (журнал)
   → Мягкая врезка в тексте: «наборы для 6+»
   → Каталог с фильтром «Возраст 6+»
   → Карточка: сложность 1/5, ~3 часа, крупные детали
   → Отзывы других родителей с фото
   → В корзину → Чекаут без регистрации
   → Заказ падает в Telegram
```
Критические точки: статья должна отвечать на вопрос, а не продавать; ссылка на каталог —
в теле текста, не баннером; на карточке сложность видна до прокрутки.

### B. Алиса — «увидела в ленте»
```
TikTok, таймлапс сборки
   → /universe/anime (лендинг вселенной, не главная)
   → Скролл витрины
   → Карточка: цена, размер на стене, «~9 часов»
   → Полоса «до бесплатной доставки 610 ₽»
   → Добор мини-набора → В корзину
   → Чекаут в один экран, оплата
```
Критические точки: лендинг вселенной грузится < 2,5 с на 4G; цена видна без прокрутки;
чекаут в один экран без обязательной регистрации.

### C. Дмитрий — «знает, чего хочет»
```
Яндекс «алмазная мозаика игра престолов купить»
   → Карточка товара напрямую из выдачи
   → Спецификация, макро-фото фактуры
   → Отзывы с деталями
   → «Из этой вселенной» → добавляет второй набор
   → Корзина → Чекаут
   → Через месяц: письмо «собрали? вот что вышло нового» → повтор
```
Критические точки: карточка самодостаточна как точка входа — с навигацией, доверием
и кросс-линками. Спецификация детальная, без маркетингового тумана.

### D. Покупатель подарка
```
Яндекс «что подарить фанату Гарри Поттера»
   → Подарочный гид (журнал)
   → /gifts → подборка по получателю и бюджету
   → Сомнение «вдруг не угадаю» → Сертификат
   → Чекаут → сертификат на почту
```

## 6. Структура сайта и перелинковка

Полная карта — в `06-SITEMAP.md` и `assets/sitemap-mindmap.svg`.

**Правило перелинковки:**
у каждой страницы **минимум 3 входящие** и **минимум 3 исходящие** внутренние ссылки.

Четыре слоя связей, ни один не кричит:

1. **Контекстные ссылки в тексте** — цвет текста не меняется, подчёркивание 1 px
   с прозрачностью 35%. Уплотняется при наведении.
2. **Смысловые мосты** — в конце статьи «Собрать своими руками» с 3 товарами по теме;
   на карточке «Из этой вселенной», «Похожие по сложности», «Статья по теме».
3. **Хлебные крошки** — на всех страницах, кроме главной.
4. **Подвал-карта** — полная структура в 4 колонки. Даёт исчерпывающую перелинковку
   в одном месте, не засоряя тело страниц.

## 7. Контент-маркетинг

Шесть рубрик журнала. Каждая ведёт в свою часть каталога.

| Рубрика | О чём | Ведёт в | Пример |
|---|---|---|---|
| **Гид по вселенным** | Разборы франшиз, подборки кадров | `/universe/*` | «10 кадров из Хогвартса, которые просятся на стену» |
| **Мастерская** | Как собрать, ошибки, оформление в раму | `/how-it-works` | «Пять ошибок новичка в алмазной мозаике» |
| **Истории** | Реальные истории клиентов, интервью | `/gallery` | «Как мозаика заменила мне вечерний сериал» |
| **Подарочные гиды** | Сезонные подборки по поводу | `/gifts` | «Что подарить фанату аниме до 2 000 ₽» |
| **Релакс и польза** | Антистресс, моторика, цифровой детокс | `/catalog` | «Почему монотонная работа руками снимает тревогу» |
| **Закулисье** | Как делаем схемы, производство | `/about` | «Как кадр из фильма превращается в 24 цвета» |

**Ритм:** 2 материала в неделю. Понедельник — утилитарный (гид, мастерская),
четверг — эмоциональный (история, закулисье).

**Правило для каждой статьи:**
отвечает на вопрос целиком, даже если человек ничего не купит. Продающая врезка — одна,
в середине текста, и по теме. Внизу — 3 товара из смежной категории.
Статья, которая обрывается на «а подробнее — купите», не работает ни для SEO, ни для доверия.
