# Карта риска промышленной автоматики — презентация пилота для «Акульчев»

## Готовые файлы

- `out/Akulchev_karta_riska_avtomatiki_pilot.pptx` — презентация, 10 слайдов, 16:9
- `out/Akulchev_karta_riska_avtomatiki_pilot.pdf` — PDF-копия
- `SOURCES.md` — список источников со ссылками
- `FACTS-vs-METHOD.md` — что подтверждено фактами о «Акульчев», а что является предлагаемой методикой
- `images/README.md` — какая картинка на какой слайд и как добавить оставшиеся
- `prepare_images.py` — подготовка кадров и иконок из `images/source/`

## Структура

| № | Слайд | Назначение |
|---|---|---|
| 1 | Титул | тема и предложение |
| 2 | Почему тема актуальна для «Акульчев» | подтверждённые факты со ссылками |
| 3 | Что именно проверяется | 6 классов компонентов + вопрос аудита |
| 4 | Как проходит пилот | 7 шагов + «производство не затрагивается» |
| 5 | Метод оценки | веса риск-скоринга, категории, приоритет источников |
| 6 | Как выглядит результат | таблица реестра (условный пример) + мини-heatmap |
| 7 | Что предприятие получает | 4 результата пилота |
| 8 | Пилот | объём, 0 ₽, сроки, что нужно от предприятия, CTA |
| 9 | Что дальше | три ценовых ориентира после пилота |
| 10 | Приложение | источники |

Основной текст слайдов 1–9 составляет 9 слайдов, как просил промт; слайд 10 — приложение
со ссылками, которое промт требовал отдельно.

## Шрифты

- **Montserrat** — заголовки, крупные числа, CTA
- **Calibri** — основной текст, описания
- **Arial** — таблицы, подписи к данным, числа, сноски, ссылки

Montserrat не входит в стандартную поставку Office. Если на машине, где открывают
презентацию, его нет, PowerPoint подставит замену и заголовки поедут. Шрифт бесплатный:
https://fonts.google.com/specimen/Montserrat

## Как пересобрать

```bash
npm install pptxgenjs
export PPTX_SKILL=<путь к pptx-скиллу>        # нужен только для applyTheme
python3 prepare_images.py                      # кадры и иконки из images/source/
node build_deck.js
```

Сборка печатает, сколько кадров подставлено и каких ещё не хватает.

Темой, палитрой и геометрией управляют объекты `THEME`, `HEX` и константы `SW/SH/M/BODY_TOP`
в начале `build_deck.js`. Акцентный цвет меняется в одном месте — `THEME.colors.accent1`
(и `accent2` — его светлый вариант для тёмных слайдов).
