# Изображения презентации

Положите сюда готовые файлы и пересоберите презентацию — скрипт подставит их сам.
Пока файла нет, на слайде рисуется размеченный плейсхолдер с описанием нужного кадра,
поэтому макет уже можно смотреть и править.

## Как вставляются

Картинки вставляются с кадрированием «по заполнению» (`sizing: cover`), то есть
подгоняются под area слайда с обрезкой по краям, без искажения пропорций. Если кадр
важен целиком — скажите, поменяю на вписывание в рамку.

Поддерживаются `.png` и `.jpg` (расширение в файле `build_deck.js`, объект `IMG_MAP`).

## Иконки

Иконки не требуются: роль иконок выполняют залитые круги с номерами шагов и буквенными
кодами компонентов (ПЛК, HMI, VFD, SERVO, I/O, IPC). Это единый мотив презентации.
Если захотите подставить сгенерированный набор иконок — скажите, добавлю.
