# PROMPTS ДЛЯ ИЗОБРАЖЕНИЙ К ПРЕЗЕНТАЦИИ «КАРТА РИСКА ПРОМЫШЛЕННОЙ АВТОМАТИКИ»

## Общие правила
- фотореалистичная современная промышленная съёмка;
- современное пищевое производство;
- чистый цех, нержавеющая сталь, шкафы автоматики, конвейерные линии;
- без футуристических голограмм и киберпанка;
- без читаемых логотипов реальных брендов;
- без текста внутри изображения;
- без водяных знаков;
- естественный промышленный свет;
- люди в нормальных СИЗ;
- изображения должны выглядеть как корпоративная фотография реального завода.

Для фоновых изображений оставлять свободную область под текст.

## Прозрачные иконки
**Формат:** 1:1, 2048×2048, transparent background.

**Prompt:**
A consistent set of 8 clean industrial line icons on transparent background, each isolated and clearly separated: PLC controller, HMI panel, variable frequency drive, servo drive, remote I/O module, industrial PC, spare part on shelf, migration/replacement symbol using two hardware modules and a simple arrow. Minimal technical vector style, dark graphite outlines, one restrained accent color, no text, no letters, no logos, presentation-ready, consistent stroke width.

## Что лучше собирать в самой презентации, а не генерировать картинкой
- риск-скоринг 30/20/20/15/15;
- таблицу примера отчёта;
- процесс «выбор линии → выезд → анализ → карта риска»;
- тарифную таблицу;
- heatmap конкретных компонентов.

Причина: здесь важна точность текста и чисел. AI-картинка должна давать визуальный контекст, а данные и схемы должны оставаться редактируемыми объектами презентации.
