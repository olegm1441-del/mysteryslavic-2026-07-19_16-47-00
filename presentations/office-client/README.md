# Продай за меня — Офисы. Клиентская презентация

Клиентский дек по офисной вертикали. Адаптирован из жилого клиентского дека
(«Освободим квартиру под ключ») под выводы кастдева и офисный источник истины.

**Дек собран полностью:** все картинки, иконки и QR на местах.

## Файлы

| Файл | Что это |
|---|---|
| `Продай_за_меня_ОФИСЫ_клиентская.pptx` | Дек, редактируемый |
| `Продай_за_меня_ОФИСЫ_клиентская.pdf` | Тот же дек на просмотр и в мессенджер |
| `01_ПЛАН_ПРЕЗЕНТАЦИИ.md` | Структура 14 слайдов, что изменено против жилого дека, и полный расчёт слайда 07 |
| `02_ПРОМТЫ_КАРТИНОК.md` | Промты на все 8 картинок — рабочий стандарт для пересъёмки и следующих деков |
| `build_deck.js` | Генератор дека (pptxgenjs). Правки текста и цифр — здесь |
| `prep_images.py` | Доводка картинок под вёрстку: подложки, прозрачность, кадрирование |
| `src-images/` | Исходники P1–P8 из ChatGPT, как пришли |
| `assets/` | Всё, что реально уходит в дек: обработанные картинки, фактуры, лого, иконки, QR |

## Пересборка

```bash
npm install pptxgenjs
python3 prep_images.py     # только если поменялись исходники в src-images/
node build_deck.js
```

## Что стоит перепроверить

- **Цифры слайда 07** — модель на референсном объекте 300 м² / 25 мест. Полный расчёт с разбивкой
  по категориям в `01_ПЛАН_ПРЕЗЕНТАЦИИ.md`. Меняются в `build_deck.js`, блок `07`.
- **QR** — сейчас в деке коды из актуального партнёрского дека: Telegram `t.me/aelart`,
  WhatsApp `wa.me/qr/VNFQXRYLB4YVL1`. Перекрашены в фирменную палитру, сканируемость проверена.
  Другие коды — положить в `assets/qr-telegram.png` и `assets/qr-whatsapp.png`.

## Дизайн-система (унаследована от жилого дека)

- Шрифт: **Inter**
- Палитра: `#0C1D28` тёмно-синий · `#F7F1E7` кремовый · `#C89B45` золото · `#D9BC7A` светлое золото
- Формат: 16:9, 13.333 × 7.5"
- Ритм: тёмный / светлый слайд через один
- Фоторендеры идут с запечённой подложкой под текст — на слайде поверх них ничего не затемняется
