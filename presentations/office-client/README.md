# Продай за меня — Офисы. Клиентская презентация

Клиентский дек по офисной вертикали. Адаптирован из жилого клиентского дека
(«Освободим квартиру под ключ») под выводы кастдева и офисный источник истины.

## Файлы

| Файл | Что это |
|---|---|
| `01_ПЛАН_ПРЕЗЕНТАЦИИ.md` | Обновлённая структура: 14 слайдов, что изменилось против жилого дека и почему |
| `02_ПРОМТЫ_КАРТИНОК.md` | 8 промтов для ChatGPT: стиль-блоки, формат, композиция, куда вставляется |
| `Продай_за_меня_ОФИСЫ_клиентская.pptx` | Сам дек, редактируемый |
| `Продай_за_меня_ОФИСЫ_клиентская.pdf` | Тот же дек на просмотр и в мессенджер |
| `build_deck.js` | Генератор дека (pptxgenjs). Правки текста удобнее делать здесь и пересобирать |
| `assets/` | Фактуры, лого, золотые иконки, временные иллюстрации |

## Что осталось подставить

1. **Картинки P1–P8** — сгенерировать по промтам, положить в `assets/`.
   В деке места помечены: полноэкранные — золотым чипом `P1` / `P2` / `P7` в правом нижнем углу,
   вставные — пунктирной рамкой с кодом (`P3` на слайде 3, `P8` на слайде 9).
2. **QR-коды Telegram и WhatsApp** — на слайде 14 стоят две рамки-заглушки.
3. **Цифры примера расчёта** (слайд 7) — сейчас взяты из референсного пилотного офиса
   ~300 м² / 25 рабочих мест, помечены как пример.

Иллюстрации на слайде «Три пути» — временные, нарисованы в фирменной палитре.
Их можно оставить или заменить на P4–P6 из ChatGPT.

## Пересборка

```bash
npm install pptxgenjs
node build_deck.js
```

## Дизайн-система (унаследована от жилого дека)

- Шрифт: **Inter**
- Палитра: `#0C1D28` тёмно-синий · `#F7F1E7` кремовый · `#C89B45` золото · `#D9BC7A` светлое золото
- Формат: 16:9, 13.333 × 7.5"
- Ритм: тёмный / светлый слайд через один
