# Продай за меня — Офисы. Клиентская презентация

Клиентский дек по офисной вертикали, 12 слайдов. Собран полностью: картинки, иконки, три QR.

## Как устроена сборка (важно)

Дек прошёл через ручную правку: структура, порядок слайдов и часть текстов правились
не скриптом, а руками в редакторе. Поэтому пайплайн двухступенчатый:

```
src-images/deck-v2-hand-edited.pptx     ручная версия — источник истины по вёрстке
            │
            └── edit_deck.py            точечные правки поверх неё
                        │
                        └── Продай_за_меня_ОФИСЫ_клиентская.pptx
```

**`build_deck.js` больше не собирает актуальный дек** — он остался как генератор первой
версии и как справочник по токенам дизайн-системы. Запускать его не нужно: он затрёт
ручную вёрстку.

Правки текста удобнее всего делать прямо в `.pptx`. Если правка структурная и должна
воспроизводиться — добавить её в `edit_deck.py` и прогнать `python3 edit_deck.py`.
